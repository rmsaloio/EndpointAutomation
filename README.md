# EndpointAutomation 🚀

A collection of PowerShell scripts designed to automate and simplify endpoint management tasks in Microsoft environments. 

---

## 📌 Overview

This project provides tools that can help with automation across various Microsoft 365 and Azure-related tasks. 
It includes scripts that may assist with tasks such as:

- Device data collection  
- Application and compliance reporting  
- Intune configuration exports  
- Administrative maintenance and cleanup

---

## ⚙️ Requirements

- PowerShell 5.1 or higher  
- Common modules: `Microsoft.Graph`, `AzureAD`, `MSOnline`, etc.  
- Appropriate permissions in Microsoft 365 or Azure environments
